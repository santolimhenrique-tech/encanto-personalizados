# Hero cinematográfica

Fotografia fornecida integrada em WebP responsivo (640, 1024 e 1672 px), com original preservado. No mobile, a imagem ocupa a faixa superior e o texto vem abaixo para preservar todos os rostos. A seção oval anterior permanece imediatamente depois.

Abertura: até 1,4 segundo, somente uma vez por sessão; sem espera de recursos. Clique ou teclado dispensam a abertura. SessionStorage indisponível: abertura limitada nesta navegação. Movimento reduzido e ausência de JavaScript: abertura dispensada. CSS também encerra visualmente a abertura se o script de conclusão falhar.

Não foi fornecida uma referência acessível do projeto AWL: a transição segue a descrição do pedido e a identidade existente.

Prévia: npm start; http://127.0.0.1:4173/. Para rever a abertura, abrir uma nova sessão de navegador ou remover a chave encanto-intro do sessionStorage. Nenhum commit, push ou deploy nesta etapa.
